# FoodStore - Programación III

## Descripción
FoodStore es una aplicación frontend de e-commerce desarrollada como parcial para la materia Programación III.

Permite:

- visualizar catálogo de productos
- buscar productos por nombre o descripción
- filtrar por categorías
- agregar productos al carrito
- modificar cantidades
- visualizar carrito
- calcular total de compra
- persistencia con localStorage
- favoritos (funcionalidad extra)

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- TypeScript
- Vite

## Cómo ejecutar el proyecto

1. Instalar dependencias:

```bash
pnpm install
```

2. Ejecutar servidor:

```bash
pnpm dev
```

3. Abrir navegador:

```txt
http://localhost:5173
```
